# Punch Clock

Android app download. Grab the latest APK from the [Releases](https://github.com/silentBan/PunchClock/releases) page.

### Installing
1. Download `PunchClock-1.3.0.apk` on your phone.
2. Open the downloaded file and tap **Install**.
3. Android will warn this app isn't from the Play Store — that's expected for a direct APK. Tap through to allow it (you'll only need to do this once).

This repo hosts only the installable app — no source code.
